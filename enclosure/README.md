# 3D-printable enclosure

A three-part printed case for the assembled board.

| File | For |
|---|---|
| `EV-Tester-case-top.stl` / `EV-Tester-case-mount.stl` / `EV-Tester-case-bottom.stl` | Any slicer / any FDM printer. |

Print in PLA or PETG, 0.2 mm layers. No supports needed for the standard orientation.
The board mounts on the M3 standoffs; the LCD, buttons, barrel jack, and J1772 (J1) cable
exit through the case openings. See [`../docs/HARDWARE.md`](../docs/HARDWARE.md) for assembly.
